# 自动贝叶斯模态识别（BAYOMA）

本技能覆盖《Operational Modal Analysis: Modeling, Bayesian Inference, Uncertainty Laws》
（Springer）第 10–16 章中与环境振动模态识别直接相关的内容，配套实现在仓库根目录下的 `python/bayoma/` 与 `matlab/+bayoma/`（Python 与 MATLAB 两套，接口一致）。

## 1. 什么时候用

- 有一批环境振动加速度（或速度、位移）记录，要识别固有频率、阻尼比、振型；
- 需要给出参数的后验变异系数，用于判断识别结果是否可用于模型修正；
- 测试分多个测组（setup），每组覆盖不同的测点，要联合识别共用的全局振型；
- 有相邻的密集模态，需要判断能否分辨、结果是否可信；
- 同一测组内各通道未共用时钟（异步采集），需要按组同步、组间建相干矩阵来识别；
- 异步采集的频带内有多阶模态，各阶对需要各自的相关性矩阵；
- 要在试验前估算记录长度，使阻尼比达到给定精度。

不适用：需要激励信号与频响函数的实验模态分析（EMA）；非平稳或明显非线性的响应；
只用单通道数据做峰值拾取。

## 2. 模型与数据要求

数据须为**平稳环境振动**。同步采集时各通道共用一个时基；异步采集时组内共用时基、
组间不共用，按第 6 节处理。核心假设（课本第 10 章）：

- 响应由若干阶模态对白噪声模态力的响应叠加而成，模态力在频域上是平坦谱；
- 通道噪声为各通道独立的带限白噪声，在选定频带内功率谱密度恒为 `Se`；
- 记录足够长，使每个频率点的周期图近似独立复高斯。

缩放 FFT（式 10.1）：

```text
F_k = sqrt(Δt/N) · Σ_{j=0}^{N-1} y_j · exp(-2πi·j·k/N),   f_k = k/(N·Δt)
```

`E[F_k F_k*] = E_k`。谱矩阵 `D_k = Re(F_k F_k*)`，`d = Σ_k F_k* F_k`。

**单位约定**：加速度用 g（9.81 m/s²），频率用 Hz，则 `S`、`Se` 为 g²/Hz，`rms` 为 g。
`p` 是数据侧变换指数、`q` 是模型侧指数：`p = 0/1/2` 表示原始数据是加速度/速度/位移，
`q = 0/1/2` 表示派生数据是加速度/速度/位移，缺省 `p = 0`、`q = 0`（加速度）。二者必须匹配，
否则频率估计正确而阻尼比与谱幅值会偏。

## 3. 单模态问题（第 12 章）

`E_k = S·D_k·u·uᵀ + Se·I_n`，其中

```text
D_k = (2πf_k)^(-2q) / [ (1-β_k²)² + (2ζβ_k)² ],   β_k = f/f_k
```

负对数似然（式 12.10，改写为只依赖一个标量二次型）：

```text
L = n·N_f·ln π + Σ_k ln(S·D_k + Se) + (n-1)·N_f·ln Se + Se⁻¹·(d - uᵀ A u)
A = Σ_k [1 + Se/(S·D_k)]⁻¹ · D_k^
```

关键结论：**给定 `{f, ζ, S, Se}` 时，`u` 的最可能值是 `A` 最大特征值的特征向量**。
于是把 `n` 维参数问题降为 4 个谱参数（式 12.13）：

```text
L̃(f, ζ, S, Se) = n·N_f·ln π + Σ_k ln(S·D_k + Se) + (n-1)·N_f·ln Se + Se⁻¹·(d - λ̂)
```

`λ̂` 是 `A` 的最大特征值。交替更新谱参数与 `u` 直到收敛。

## 4. 多模态问题（第 13 章）

`E_k = U·H_k·Uᵀ + Se·I_n`，`H_k = diag(h_k)·S·diag(h_k*)`，
`h_ik = (2πi f_k)^(-q)/(1 - β_ik² - 2iζ_iβ_ik)`。

`U`（n×m）的秩 `m0 = rank(U) ≤ min(n, m)`。取 `U = B0·α`，`B0` 为 n×m0 列正交基，
把似然降到 m0 维（式 13.15）：

```text
L = n·N_f·ln π + (n-m0)·N_f·ln Se + Se⁻¹·d + Σ_k ln|E0_k|
    - Se⁻¹·Σ_k F'_k* E0_k⁻¹ F'_k,        F'_k = B0ᵀ F_k
E0_k = α·H_k·αᵀ + Se·I_m0
```

**三个必须守住的实现要点**：

1. 最后一项是**复值二次型**，必须用复值投影 `F'_k`，不能换成 `B0ᵀ D_k B0`。用后者会丢掉
   互谱相位，模态力谱矩阵 `S` 的非对角元失去约束，`S` 的估计会收敛到与真值模相近而相位
   错误的值。
2. `B0` 不能锁死。课本用超角旋转（式 13.22–13.23）让模态形状子空间本身可转动；
   把 `φ` 限制在初始基张成的子空间内，密集模态下会停在鞍点。
3. 输出前必须统一相位基准：模态形状的整体复相位不可辨识，`φ`、`α`、`S` 三者要同步变换，
   否则 `φ ≠ B0·α`，用两者算出的似然不同。

模态力谱矩阵的结构化参数化（式 13.50–13.57）：`S = diag(s)·S0·diag(s)`，
`S0_ij = exp(i·v_ij)·sin(u_ij)`（i ≥ j），保证半正定且对角为 `s_i²`。

**密集模态的判据**：`S` 的后验变异系数超过 100%，或最可能值收敛慢、达到迭代上限。
这不是实现缺陷，而是两阶模态形状在有限记录下难以分离的直接后果（课本 13.6 节）。

## 5. 多测组问题（第 14 章）

`q` 个测组，第 `r` 组测 `n_r` 个自由度，`t_r = L_r·u`，`L_r` 为选择矩阵，`u` 为共用全局振型
（`uᵀu = 1`）。各测组可有独立的 `f^(r)`、`ζ^(r)`、`S^(r)`、`Se^(r)`。

换元 `S0^(r) = S^(r)·‖t_r‖²`、`t̃_r = t_r/‖t_r‖` 后，每个测组的似然与单模态问题同形
（式 14.31）：

```text
L_r = n_r·N_f^(r)·ln π + Σ_k ln(S0^(r)·D_k^(r) + Se^(r)) + (n_r-1)·N_f^(r)·ln Se^(r)
      + Se^(r)⁻¹·(d^(r) - t̃_rᵀ A^(r) t̃_r)
```

全局振型的最可能值是特征值问题 `B·u = λ_0·u` 的最小特征值特征向量（式 14.40）：

```text
B = Σ_r λ_r·L_rᵀL_r - Σ_r (L_rᵀ A^(r) L_r) / (‖t_r‖²·Se^(r))
λ_r = t_rᵀ A^(r) t_r / [Se^(r)·(t_rᵀ t_r)²]
```

**迭代顺序必须是**：先由式 14.41 算 `λ_r`，再构造 `B`，再更新 `u`，最后算 `c_r = uᵀL_rᵀL_r u`。
顺序错了（首轮 `λ` 全零）`B` 只剩负定项，全局振型会落到无物理意义的方向。

**生成多测组合成数据时，局部振型必须取 `t_r = L_r·u` 的对应分量，不得单独归一化**，
否则反算出的 `S^(r) = S0^(r)/‖t_r‖²` 会偏离真值 `1/‖u(dofs)‖²` 倍。

**参考自由度凝聚（式 14.17–14.20）**：参考自由度指被两个以上通道测到的自由度。把全局振型
写成 `u = L_c·u_c`（`L_cᵀL_c = I`），待求维数由自由度总数降到 `n₀₀ + n₀ + n`，式 (14.20)
的特征值问题相应降到 `2n₀×2n₀`。配套实现见 `python/bayoma/condense.py` 与
`matlab/+bayoma/condensation_matrix.m`，多测组最可能值的全局振型求解缺省在凝聚子空间内进行
（`condense` 选项，缺省开启）。

凝聚只作用于最可能值；后验协方差始终在完整的 n 维切空间内计算，开关凝聚后变异系数不变
（实测两者同为 0.002729、最大分量差 8.2e-11）。全局振型的变异系数高于单个测组按本组通道数
算出的定律值，原因是各自由度的有效约束长度不同（取各测组对该自由度的记录长度之和）：
被测到三次的自由度标准差 7.43e-4，只被测到一次的 1.16e-3–1.52e-3。以总约束时长作参照时
两者一致（全覆盖情形数值 0.001083 对六通道 9600 s 定律 0.001078，比值 1.004）。

**全局最小二乘迭代必须每轮对齐局部振型的正负号**：取 `sgn = sign(t̃_rᵀ L_r u)` 后代入。
局部振型的整体符号不可辨识，不对齐时迭代收敛到错误驻点——课本 Example 14.2 实测 MAC 仅
0.41，对齐后为 0.999999。

## 6. 异步数据（课本 10.4 节）

同一测组内不同通道未共用时钟的情形：组内同步、组间不同步。把通道分组后，组内仍按同步
模态形状处理，组间用复相干矩阵 `v` 表征模态力在组间的相关性，各测组有独立的通道噪声谱
`Se^(r)`（第 `r` 组第 `a` 通道的第 `i` 阶模态力谱乘 `v^(rs)_ij`，`v` 的秩不超过各组的
主导模态数）。

似然函数（式 10.50）仍是复高斯形式，但协方差矩阵改为分块：

```text
E_k = D₀^(1/2)·( I + S·D_k·M )·D₀^(1/2)
M = D₀^(-1/2)·(ũ·v·ũᵀ)·D₀^(-1/2),   D₀ = blockdiag(Se^(1)·I_n1, …, Se^(q)·I_nq)
```

`D₀` 取对角便于求逆与行列式，`M` 承担组间与组内各阶的耦合。单模态情形下 `v` 退化为一个
`q×q` 矩阵，其模不超过 1。

`q = 1` 时异步模型必须与同步单模态问题完全等价，这是实现的必要条件：同一份数据两侧给出
同一 `{f, ζ, S, Se}` 与同一振型（实测相对差 8e-09～2e-05，MAC 为 1）。

三处必须守住的做法：

1. `M` 必须**精确 Hermitian**。MATLAB 侧用 `triu(M) + triu(M,1)'` 构造；先作 `(M+M')/2`
   再判 `ishermitian` 仍可能返回假，`eig` 会走一般矩阵分支，特征向量不正交，负对数似然
   实测偏高约 140、`MAC` 只剩 0.943。
2. 谱参数优化的边界按数据量纲取（`d_scale = mean|F_k|²`，上下界取 `d_scale·1e±8`）。
   用与数据无关的 `1e-30~1e30` 时，有界拟牛顿法的线搜索在初值处即报相对下降收敛，
   谱参数不再前进。
3. 与不确定度定律对照时，`κ` 取实际选带折算值（半带宽除以 `f·ζ`）。只有一阶模态时
   异步模型的后验变异系数低于定律预测（实测比值约 0.72），因为组间相干信息提供了额外约束，
   而定律按独立通道数估计。

实现见 `python/bayoma/asynchronous.py`（`mpv_asynchronous`、`asynchronous_covariance`、
`simulate_asynchronous`）与 `matlab/+bayoma/asynchronous_single_mode.m`，校核记录见
`docs/VERIFICATION.md` 第 4 节。

### 6.1 异步数据的多阶模态

频带内有多阶时，把单阶的 `S·D_k·ũ·v·ũᵀ` 推广为双重求和（式 10.47）：

```text
E_k = Σ_i Σ_j h_ik·h*_jk·S_ij·( U_i·V_ij·U_jᵀ ) + D₀
U_i = blockOp(u_i, groups)（只在本组行块上非零），V_ii = I_q
紧凑形式：E_k = G·W_k·S_v·W_k^*·Gᵀ + D₀，G = [U_1 … U_m]，W_k = kron(diag(h_k), I_q)
```

各阶共用同一测组划分与同一振型矩阵，但各有独立的频率、阻尼比与相干矩阵 `V_ij`。

三条实现纪律：

1. **`S` 的规范随测组数变化**。`ng ≥ 2` 时 `S_ij` 的相位与 `V_ij` 的整体相位是同一规范
   自由度，取 `S` 实对称即固定该规范（改取复 Hermitian 会让 Hessian 沿该方向曲率为零，
   后验方差发散）。`ng = 1` 时 `V` 不存在，`S_ij` 的复相位是可辨识参数，必须取 Hermitian
   复矩阵；强行取实会使模型受限，实测单测组两阶问题的负对数似然比同步多阶实现高 41.77。
   `ng = 1` 且 `m > 1` 时形状也要放开为复向量；此时本实现的模型类**包含**同步多阶的
   `φ = B₀α`（`B₀` 实正交基、`α` 复），多出 `m(2n−2) − m(n−1)` 个形状实自由度。故单测组
   退化判据按嵌套关系写（谱参数相对差小、本模型在同步解处似然不低于最优、似然比落在额外
   自由度的 `χ²` 99% 分位内），振型 MAC 只作参考——复内积 MAC 的 `1 − MAC` 为 6.4e-6，而
   两者与真值的 `1 − MAC` 本身在 8e-4 量级，压到 1e-6 需约六倍记录时长。`m = 1` 时
   `S_11` 为实正标量、形状相位无处吸收，仍必须取实形状。
2. 似然按降维恒等式实现：取 `G` 的列空间正交基 `B`、`Bt = D₀^{-1/2}B`、`H = BtᵀBt`，
   `ln|E_k| = Σ_r n_r·ln Se_r + ln det(I + E0_k·H)`，
   `F_k^*·E_k^{-1}·F_k = |D₀^{-1/2}F_k|² − G_k^*(E0_k^{-1} + H)^{-1}G_k`。二次型必须用
   `|y_k|² − |g_k|² + g_k^*·Q_k^{-1}·g_k` 的形式（`g_k = H^{-1/2}Y_k`、`Q_k = I + H^{1/2}E0_kH^{1/2}`），
   直接展开成大数相减会丢掉全部有效位，优化器随即停在参数边界。
3. 输出前按频率升序重排各阶（`S` 的行列、`V_ij`、`phi` 的列同步重排），符号规范通过
   反号 `S` 的第 i 行与第 i 列实现，不能反号 `V_ij`（其对角元被约束为 1）。

实现见 `python/bayoma/asynchronous_multi.py`（`mpv_asynchronous_multi`、
`asynchronous_multi_covariance`、`simulate_asynchronous_multi`）与
`matlab/+bayoma/asynchronous_multi_mode.m`，校核记录见 `docs/VERIFICATION.md` 第 4.6 节。

## 7. 后验协方差

高斯近似 `C = (∇²L)⁻¹`（式 10.17）。模态形状有单位范数约束，必须用约束投影（式 12.21–12.27）：

```text
Ĉ = (∇v̂_c)·(∇²L̂_c)⁺·(∇v̂_c)ᵀ
∇²L̂_c = (∇v̂_c)ᵀ·(∇²L̂ + λ̂₁·∇²Ĝ)·(∇v̂_c)
Ĝ = 1 - uᵀu,   ∇v̂_c = blkdiag(I_4, I_n - ûûᵀ),   λ̂₁ = -λ̂/Se
```

**两条实践要点**（来自实现与校核）：

1. 直接用物理量纲做数值 Hessian，谱参数（1e2–1e6）与振型分量（1e-1）量级相差过多，
   伪逆会把小量级方向判成零方差，得到全零的变异系数。要先无量纲化，或改用切空间参数化
   `u(θ) = (u + Zθ)/‖u + Zθ‖`。解析 Hessian 同样有这个问题：实测记录的谱密度只有
   1e-11 量级时，`pinv` 的相对容差 1e-12 会把 f、z、phi 的方向判成零曲率，变异系数全部
   变成 0。做法是先按对角元做雅可比预条件 `H̃ = D⁻¹HD⁻¹`（`D = sqrt(|diag H|)`），
   求逆后再还原 `C = D⁻¹C̃D⁻¹`，使各自由参数在对角尺度上同量级。
2. 复数振型的切空间要剔除整体相位方向 `[-Im u; Re u]`，否则该方向曲率为零、方差发散。
   复情形切空间维数为 `2n-2`。
3. 协方差只在似然驻点处有意义。交替极小化在最优点附近的漂移会带来负特征值，此时方差被
   整体放大。求解前确认梯度足够小。
4. 改完协方差代码后做一次尺度不变性检查：把同一份数据整体乘一个常数（例如 1e-5），
   频率、阻尼比与各参数的变异系数不应改变。用 `S = 1` 的常规算例查不出上述预条件缺陷。

## 8. 自动选带

流程：单次 FFT 的谱矩阵秩为 1，高阶奇异值恒为 0，**判模态数必须用 Welch 平均谱**。

1. 分段加 Hanning 窗、50% 重叠求平均谱矩阵；
2. 对每个频率点做特征分解，得到按降序排列的奇异值曲线；
3. 噪声基线取最高阶曲线在全频段的中位数；
4. 在**平滑后的第一条曲线**上找峰，突出度阈值取噪声基线的 5 倍以上；
5. 再用「不低于最高谱峰 5%」过滤一次。只用基线判据时，宽带噪声在远离共振处的起伏
   （相对最高谱峰 1%–2%、却是基线的 10–25 倍）会被当成谱峰，实测使频带数从 2 变 4；
   只用比例判据时，孤立的小峰可能漏判。两条判据缺一不可；
6. 每个峰一个频带，半宽 `κ·ζ·f`（κ 缺省 10，即约半功率带宽的 5 倍），相邻频带按中点切开；
7. 峰处显著高于噪声基线的曲线条数即该频带的模态数。

## 9. 不确定度定律（第 15 章表 15.1）

以 `c = 1/(4μφ²)` 为模态信噪比、`μ = (2πf)^(2q)·Se/S`、`N_c = N_f/(2κζ) = T_d·f`：

| 参数 | 零阶定律 | 数据长度因子 |
| --- | --- | --- |
| f | `ζ/(2π·N_c·B_f)` | `B_f = (2/π)tan⁻¹κ - κ/(κ²+1)` |
| ζ | `1/(2πζ·N_c·B_ζ)` | `B_ζ = (2/π)tan⁻¹κ + κ/(κ²+1) - 2(tan⁻¹κ)²/κ` |
| S | `1/(N_f·B_S)` | `B_S = 1 - (2/κ)·(tan⁻¹κ)²/(tan⁻¹κ + κ/(κ²+1))` |
| Se | `1/((n-1)·N_f)` | `B_Se = 10` |
| u | `2(n-1)μφ/(π·N_c·B_u)` | `B_u = (2/π)tan⁻¹κ` |

总式 `ε²_x ≈ ε²_x0·(1 + α_x/c)`。**频率的零阶律分子是阻尼比 `ζ`，不是频率 `f`**，
这一项最容易写错。

用途：试验前估算记录长度；识别后判断结果是否达到预期精度；比较不同频带宽度的取舍。

### 9.1 第 16 章：Fisher 信息矩阵与参数间相关性

表 15.1 只给边际变异系数，且已在 `B_ζ`、`B_S` 里把 `ζ` 与 `S` 的相关性吸收掉。要拿到
**相关矩阵**（误差传递、多参数联合置信域）时用第 16 章：

- 长数据渐近下 `L̂^(xy) → J_xy`（Fisher 信息矩阵），`J_xy = Σ_k tr[E_k^{-1}E_k^(x)E_k^{-1}E_k^(y)]`（式 16.5–16.7）；
- 小阻尼下 `J` 有闭式（表 16.2），求逆即得后验协方差；
- 只有 `ζ` 与 `S` 显著相关，敏感度系数 `q_{ζS} ~ -√2(tan⁻¹κ)κ^{-1/2}(tan⁻¹κ + κ/(κ²+1))^{-1/2}`（式 16.35），**后验相关系数与之反号** `ρ_{ζS} ≈ -q_{ζS}`（κ=10 时约 +0.52）；
- `σ²_ζ = 1/(L^{ζζ}(1-q²_{ζS}))`、`σ²_S = 1/(L^{SS}(1-q²_{ζS}))`（式 16.37）；
- 振型与其余参数的相关系数为 `O(N_f^{-1/2})`，长记录下可忽略。

调用：Python `bayoma.posterior_matrix(f, z, S, Se, kappa, duration, nch, q)` 返回 `cov`、
`corr`、`coefv`、`fisher`；MATLAB `bayoma.uncertainty_matrix(...)` 返回同名字段。
**表 16.2 求逆的边际值比表 15.1 小 0–1.6%**（`S` 差最多，因 `B_S` 已吸收部分相关性），
两者不一致时以第 15 章为准做精度预估、以第 16 章做相关性分析。一阶信噪比修正
（式 16.43–16.44）不重复实现，表 15.1 的 `α_x/c` 已等价。

## 10. 判读结果

- `sn = S/(4·Se·ζ²)` 为模态信噪比。`sn` 大（>100）时频率与振型可靠，阻尼比仍需看变异系数。
- 阻尼比的变异系数通常比频率大两个量级，这是问题的性质：阻尼比由半功率带宽决定，
  对谱的形状敏感。
- 频带内模态数 ≥ 通道数时部分参数不可辨识，`Se` 的最可能值可能落在 0，`Se` 与 `sn` 不可用。
- 振型只到单位范数，符号与整体相位无意义；比较振型用 MAC。

### 10.1 结果分组：读新增的两组字段

结果文件在基础字段外分两组：`recognition`（识别结果）与 `assembly`（仅异步数据的组装
结果）。读结果时按下面四件事逐项看。

**每个识别频率属于哪个频带、代入的初值是多少。** `recognition.modes` 逐阶给出
`order`、`band_index`、`order_in_band`、`frequency`、`band_lower`、`band_upper`、`f0`。
`f0` 是该频带实际代进优化的频率初值，不是用户输入的原值（自动选带或补点时会被改写）。
识别结果落在频带边缘、或与 `f0` 相差超过半个半功率带宽时，先怀疑频带划得太窄。

**两阶模态是否可分。** `recognition.separation` 用「频率间隔 ÷ 半功率带宽」判定：
`separation_in_bw = |f_i − f_j| / max(2 ζ_i f_i, 2 ζ_j f_j)`，小于 2 判为密集模态。
同一条记录里还要看 `f_correlation`：两阶频率的后验相关系数接近 ±1 而区分度小于 1 时，
两阶频率实际不可分辨，报告里应写成「一阶密集模态对」，不要给出两个独立的频率估计。

**振型是否可靠。** `recognition.shape_uncertainty` 逐阶给出 `coefv`（通道空间协方差
迹的平方根）与逐通道 `std_per_channel`、`ci95_halfwidth_per_channel`。`coefv` 与
第 9 节的定律对照，比值在 0.8–1.2 说明识别正常；某个通道的标准差明显大于其它通道时，
该通道的测点或安装可疑，优先排查而不是直接采信振型。

**联合后验协方差怎么用。** `recognition.joint_covariance.index` 给出矩阵的行列顺序
（每项含 `name`、`kind`、`band_index`、`order`），矩阵本身在
`recognition.joint_covariance_matrix`。矩阵是**分块对角**的：不同频带的频点不重叠、
似然可加，跨频带的相关系数恒为 0，这不是近似。只取同一频带内的子块做相关性分析，
跨频带做相关会得到恒为 0 的无意义结果。

异步数据另有 `assembly` 组：`assembly.uncertainty` 把组装后振型的不确定性分解成
`recognition_coefv`（识别环节）与 `assembly_coefv`（组装环节），两者平方和等于
`total_coefv` 的平方（按矩阵迹核对，实测相等）。若 `assembly_coefv` 占比过半，说明
不确定度主要来自测组之间相干矩阵的估计，增加测组的同步记录时长比延长单个测组更有效。

## 11. 使用说明

### 11.1 本技能什么时候被加载

技能在会话开始时进入技能目录，模型在遇到「模态识别、OMA、阻尼比、振型、多测组、后验协方差、
不确定度定律」一类任务时按名字调用，读入本文件正文。技能本身不执行计算，计算走第 11.2 节
列出的两套实现。

安装方式（二选一，正文内容相同）：

| 方式 | 操作 | 生效时机 |
| --- | --- | --- |
| 账号级技能 | 把本目录复制到 `%USERPROFILE%\.dsh\skills\bayoma-oma\` | 下一个会话开始 |
| DSH 插件 | `plugin_manager action=install_bundle target=<本机绝对路径>\plugin\dsh-bayoma-oma` | 重启 Harness 后 |

校验是否生效：在新会话里问「列出可用技能」，或直接说「用 bayoma-oma 技能识别这批数据」。

### 11.2 调用计算

Python，最简一次调用：

```python
import sys
sys.path.insert(0, r"python")
import bayoma
out = bayoma.bayoma(tdata, fs, f1f2=[[0.9, 1.1]], f0=[[1.0]])
# out 的键：f, z, Sii, Se, phi, rms, S, coefv, cmat, sn, bands, nch, fs
# recognition（结果分组，见第 10.1 节）；异步识别的 JSON 结果另含 assembly
```

要谱图与振型图时加三个关键字：

```python
geom = {"channels": [{"name": "ch1", "position": [0, 0, 0], "direction": [1, 0, 0]},
                     {"name": "ch2", "position": [0, 0, 0.6], "direction": [1, 0, 0]}],
        "connections": [[0, 1]]}
out = bayoma.bayoma(tdata, fs, f1f2=[[0.9, 1.1]], f0=[[1.0]],
                    geometry=geom, figure_dir="figs", spectra=True)
```

`geometry` 缺省时不画振型图（`recognition.spatial` 给 `available = false` 与原因）；
`spectra=True` 才把 PSD 谱与 SV 谱写进结果，长记录时建议打开以核对频带与初值。

不给 `f1f2` 与 `f0` 即走自动选带：

```python
out = bayoma.bayoma(tdata, fs)
print(out["bands"], out["f"], out["z"])
```

MATLAB：

```matlab
addpath(genpath('matlab'));
IN.tdata = tdata; IN.fs = 100; IN.f1f2 = [0.9 1.1]; IN.f0 = {{1.0}};
OUT = bayoma.bayoma(IN);
```

机器可读接口（两套实现共用同一份 JSON 描述，供其余软件或智能体直接调用）：

```powershell
cd python
python -m bayoma.io_json job.json --out result.json
```

```matlab
result = bayoma.io_json('job.json', 'result.json');
```

字段的合法取值与形状由 `schema\` 下两份 JSON Schema 给出
（`job.schema.json` 校验描述文件、`result.schema.json` 校验结果文件，均为 2020-12、
顶层 `additionalProperties` 为 `false`）。接入方无需解析文字说明即可先校验描述、跑完再
校验结果。同一字段在三条识别路径下形状一致：`f`、`z`、`Sii`、`Se`、`rms`、`sn` 一律
一维数组（只有一阶也写 `[x]`），`phi` 一律二维，`coefv` 各项沿用同一形状，`input` 内的
`fs`/`nch`/`nt`/`duration` 是数字。MATLAB 的 `jsonencode` 无法区分标量与长度 1 的数组，
写盘前经 `bayoma.to_json_tree` 显式化形状，故两侧产物对同一 schema 均为 0 错误。该结论由
`python/tests/check_matlab_schema.py` 对 MATLAB 写出的结果文件复核，不靠人工比对。

### 11.3 调用前必须确认的四件事

| 项 | 怎么确认 | 后果 |
| --- | --- | --- |
| 数据是否同步、是否平稳 | 各通道同一时基，无趋势项 | 不同步会使振型相位失去意义 |
| 单位（g 还是 m/s²） | 与 `S`、`Se`、`rms` 的单位一致 | 只影响幅值，不影响 f 与 z |
| `p` 与 `q` 是否匹配 | 原始数据加速度 `p=0`，模型侧加速度 `q=0` | 不匹配时 f 正确、z 与谱幅值偏 |
| 频带是否覆盖目标模态 | 先用自动选带的 `bands` 看一遍 | 频带过窄会截断半功率带宽，阻尼比偏大 |

### 11.4 判读与交付

- 先看 `sn` 与 `coefv.z`：`sn > 100` 时频率与振型可靠；阻尼比的变异系数通常比频率大两个
  数量级，这是问题的性质。
- 报告阻尼比时同时给出变异系数与记录长度，三者一起才有解释力。
- 密集模态给出频带内的模态数、`S` 的变异系数，并说明该情形下互谱估计的可辨识性。
- 振型给单位范数形式与 MAC，不给符号或整体相位。
- 交付结果时直接用结果文件的两组字段，不要自己另建索引：`recognition.modes` 说明每个
  频率属于哪个频带、代入的初值是多少；`recognition.separation` 说明是否密集模态；
  `recognition.joint_covariance.index` 对应矩阵的每一行；`recognition.shape_uncertainty`
  给出逐阶、逐通道的振型不确定性。异步数据另有 `assembly` 组，其 `uncertainty` 已把
  识别与组装两个环节的方差分开，直接引用即可。

### 11.5 常见误用

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 阻尼比忽大忽小 | 记录太短 | 加长到 2400 s 以上再比较 |
| 自动选带把噪声判成峰 | 用单次 FFT 的谱矩阵判模态数（秩为 1） | 改用 Welch 平均谱 |
| 多测组 `S` 比真值大若干倍 | 局部振型被单独归一化 | 取 `t_r = L_r·u` 的对应分量 |
| 变异系数全为 0 | 谱参数量级与振型分量相差过多，伪逆截断 | 按对角元做雅可比预条件后求逆 |
