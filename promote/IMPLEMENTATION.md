## 1. 复用检索（要求 7 的前置，全局规则第 7 条）

实现前先检索是否已有可直接复用的 BAYOMA 实现，结论见 `docs/REUSE_SEARCH.md`：

- PyPI 上的 `pyoma` 是 OMA（Orthologous MAtrix）生物信息数据库的 HDF5 读取库，
  与运行模态分析无关；`pyoma2`、`bayoma` 在 PyPI 上不存在。
- 课本作者的 pcode 参考包已加密为 `.p` 文件，
  不可读，只能依据其说明文件（`Contents_bayoma.m`、`readme.pdf`）对齐接口契约。
- 本机既有的 MATLAB 代码是同一作者的早期版本，可作为行为参照，但同样不可作为
  可直接调用的库。

结论：自行实现，并把检索范围与判定依据写入交付文档。

## 3. Python 实现顺序

按「单模态 → 多模态 → 多测组 → 后验协方差 → 自动选带 → 接口层」推进，每一步先用
合成数据与已知真值比对，再进入下一步。

### 3.1 单模态

先写 `dynamic_factor` 与其对 `f`、`ζ` 的一阶二阶导数（表 12.2），再写降维似然
（式 12.13）。最可能值用 `scipy.optimize.minimize` 的 L-BFGS-B，在 `log f, log ζ,
log S, log Se` 空间搜索，外层交替更新 `A` 的最大特征向量。

后验协方差按表 12.1–12.6 逐块拼 Hessian。**这里发现过一个真实错误**：`b_ff`、`b_fz`、
`b_zz` 三项漏了因子 `S`（写成 `Se·S·D'(...)`，应为 `Se·S²·D'(...)`），使解析协方差与
有限差分相差 4%–5%。修正后比值回到 1.000。

### 3.2 多模态

按式 13.15 实现降维似然，用 `einsum` 批量计算，避免逐频率循环（逐频率循环在 2400 s
记录上要跑 600 s 以上）。

**三处实质缺陷，逐个定位并修正**：

1. **频率初值取错曲线**。原实现逐条奇异值曲线各取一个峰，第二条曲线上的噪声起伏会被
   当成模态。改为只在第一条（最高）曲线上用 `scipy.signal.find_peaks` 找峰，按突出度
   排序取前 `n_mode` 个，峰数不足时在最大峰两侧按 `3·Δf` 间隔补点。
2. **似然丢失互谱相位**。原实现把最后一项写成 `B0ᵀ·Re(F_k F_k*)·B0` 的二次型，丢掉
   `Im(E0⁻¹)` 与互谱虚部的耦合，`S` 的非对角元失去约束（估计得 `-0.10-0.33j`，真值
   `0.3536+0.3536j`）。改为复值投影 `F'_k = B0ᵀ F_k`，二次型用 `F'_k* E0_k⁻¹ F'_k`。
3. **相位基准不一致**。输出时只对 `φ` 做了符号翻转，`α` 与 `S` 没同步，导致
   `φ ≠ B0·α`（差 1.336），两者算出的似然差 483。改为统一做复相位变换，三者同步。

另外补上超角旋转（式 13.22–13.23）：原实现把 `φ` 锁在初始基张成的子空间内，密集模态
下真实解会转出该子空间，交替极小化只能停在鞍点（Hessian 有两个负特征值）。加上
`m0·(n-m0)` 个超角作为额外自由参数并联合精化后，似然下降 465.5，负特征值消失。

### 3.3 多测组

按式 14.31 写逐测组似然，按 14.3.3 节的三步迭代。**两处顺序错误**：

1. `setup_nllf` 的最后一项写成逐频率除以 `Se`（等价于 `N_f·d/Se`），使频率漂到 6.6 Hz、
   `Se` 到 9e4。改为整段先相减再除一次。
2. 构造式 14.40 的 `B` 之前没先更新 `λ_r`，首轮 `λ` 全零，`B` 只剩负定项，全局振型
   落到无物理意义方向（MAC 0.725）。改为先算 `λ_r`（式 14.41）再构造 `B`。

合成数据侧也有一个必须记住的约定：**局部振型取 `t_r = L_r·u` 的对应分量，不得单独
归一化**，否则反算出的 `S^(r)` 会偏离真值。

### 3.4 参考自由度凝聚

全局最小二乘的第一版没有对齐各测组局部振型的正负号，课本 Example 14.2 得
MAC 仅 0.41。诊断表明课本给出的全局振型确实是目标函数的全局最优（目标函数值
8.351e-04 对 8.350e-04），且在课本解处只有符号对齐后才满足驻点条件（残差
1.856e-04 对未对齐的 2.461e-01）。改成每轮按当前 `u` 取
`sgn = sign(t~_rᵀ L_r u)` 后，两侧均得
`u = [0.1624 0.2860 0.3153 0.4767 0.5466 0.5161]`，与课本 MAC 0.999999。

凝聚只作用于最可能值的全局振型求解，后验协方差仍在完整的 n 维切空间内计算。核对了
`condense=True` 与 `condense=False` 两种设置：全局振型变异系数同为 0.002729，最大分量差
8.2e-11，说明凝聚不改变后验方差。多测组全局振型的变异系数高于单个测组按本组通道数算出的
定律值，原因是各自由度的有效约束长度不同：被测到三次的自由度标准差 7.43e-4，只被测到一次的
1.16e-3–1.52e-3。以总约束时长作参照时，全覆盖情形与定律之比为 1.004，见
`docs/VERIFICATION.md` 3.3 节。

### 3.5 后验协方差

三版迭代后的方案是**切空间参数化**：

1. 第一版直接用约束投影加物理量纲的数值 Hessian，变异系数全为 0——谱参数量级 1e2–1e6
   与振型分量 1e-1 相差过多，伪逆把振型方向判成零方差。
2. 第二版先无量纲化再求 Hessian，比值仍只有 0.58/0.56/0.42。
3. 第三版为每阶模态形状取正交切空间基 `Z`，令 `u(θ) = (u + Zθ)/‖u + Zθ‖`，直接对该
   坐标做中心差分 Hessian。单模态与解析结果一致到千分之一（相对步长 1e-4 最佳）。

复数振型的切空间还要剔除整体相位方向，维数从 `2n-1` 降到 `2n-2`，否则该方向曲率为零、
方差发散（修复前振型变异系数达 721.8）。

### 3.6 自动选带

**单次 FFT 的谱矩阵秩为 1，高阶奇异值恒为 0**，用它判模态数会得到零噪声基线。改为
Welch 平均谱（Hanning 窗、50% 重叠）。另外发现平滑窗宽不能取太宽（原 10·Δf 把 1.0 与
1.4 Hz 两个峰糊成一个 1.355 Hz 的峰），改为 `max(4·Δf, 0.002·带宽)`。

谱峰的判定用了两轮才定下来。第一轮只有「峰必须显著高于噪声基线 5 倍」，在合成数据上
仍把 1.19、1.73 Hz 的宽带噪声起伏判成模态（这两个点的平滑曲线为最高谱峰的 2.0% 与
1.1%，却高出噪声基线 25 倍与 14 倍），频带数从 2 变成 4。第二轮加入「不低于最高谱峰
5%」的比例判据，噪声起伏（1%–2%）与真实共振峰（68%、99%）被分开，两套实现都判出
两个单阶频带。两条判据缺一不可：只用比例判据时孤立的小峰可能漏判，所以噪声基线判据
保留。

### 3.7 异步数据

似然函数按测组把模态形状分块，用复相干矩阵 `v` 表征组间相关性、各测组独立的通道噪声谱
`Se⁽ʳ⁾`。实现要点见 `python/bayoma/asynchronous.py` 与 `matlab/+bayoma/asynchronous_single_mode.m`。
三处缺陷是写完校核才暴露的：

1. `M = D₀^{-1/2}(ũ·v·ũᵀ)D₀^{-1/2}` 在 MATLAB 侧不精确 Hermitian。先作 `(M+M')/2` 后
   `ishermitian` 仍返回假，`eig` 走一般矩阵分支，特征向量不正交（`|Q'Q−I| = 1.08e-1`），
   负对数似然偏高约 140、MAC 只剩 0.943。改用 `triu(M) + triu(M,1)'` 后两侧一致到 1e-8。
2. 谱参数优化边界按数据量纲取（`d_scale = mean|F_k|²`，上下界 `d_scale·1e±8`）。原先用
   与数据无关的 `1e-30~1e30`，有界拟牛顿法的线搜索在初值处即报相对下降收敛，谱参数不动。
3. MATLAB 的 `fmincon` 用 interior-point 在 `maxIter = 200` 内不收敛，改 `sqp` 后 6 次
   外层迭代收敛。

### 3.7.1 异步数据的多阶模态

式 (10.47) 把单阶的 `S·D_k·ũ·v·ũᵀ` 推广为 `Σ_i Σ_j h_ik h*_jk S_ij (U_i V_ij U_jᵀ)`，
`U_i = blockOp(u_i, groups)` 只在本组行块上非零。实现遇五类问题：

1. **`S` 的规范随测组数切换**。`ng ≥ 2` 时 `S_ij` 的相位与 `V_ij` 的整体相位是同一规范
   自由度，取 `S` 实对称即固定该规范；`ng = 1` 时 `V` 不存在，`S_ij` 的复相位是可辨识
   参数，必须取 Hermitian 复矩阵。漏做后者时单测组两阶问题的负对数似然比同步多阶实现
   高 41.77（7544.520922 对 7502.751306）。
2. **降维后二次型不能直接展开**。把 `n × n` 的 `E_k` 投影到 `G` 的列空间后，
   `F^* E^{-1} F` 若按 `|y|² − |g|² + g^* Q^{-1} g` 以外的形式展开会丢光有效位（量级
   1e5 的两项相减）。实现按该形式分两项计算。
3. **频率初值必须逐频点取主方向**。最初按带内平均求主特征向量，平均后组内块失去秩一性，
   主特征向量与真值近正交（MAC 0.0027、0.3761），初值处负对数似然是真值的 4.49 倍
   （102386.99 对 22824.22），有界拟牛顿法从该点出发落进劣质局部极小。改为逐频点取主
   方向、按 `sqrt(λ − S_e)` 缩放拼接后，同一算例的初值点与最可能值重合。
4. **噪声谱初值高估一个量级**。原来按全带最小特征值取，改为组内块局部平滑最小特征值谱
   的带内 10% 分位数后与真值同量级。
5. **单测组时形状必须放开为复向量**。同步实现的形状是 `φ = B₀α`（`B₀` 实正交基、
   `α` 复坐标），其复相位吸收到 `S` 的对角项里；异步实现若强制实形状，
   `(B₀α)·diag(h) ≠ B₀·diag(h)·α`，两者的模型类不嵌套，单测组两阶问题的负对数似然
   差 0.127。放开为复形状后模型类**包含**同步多阶，多出 `m(2n−2) − m(n−1)` 个形状实
   自由度（`n = 5`、`m = 2` 时为 8）。

放开复形状后单测组退化按模型类嵌套关系校核：Python 侧 `f` 相对差 1.6e-7、`z` 6.8e-5、
`S` 对角 2.0e-5、`2|ΔL| = 5.5e-3` 对 `χ²₈` 的 20.09；MATLAB 侧 `f` 5.5e-7、`z` 6.3e-5、
`S` 对角 2.8e-4、`2|ΔL| = 2.43` 对 `χ²₄` 的 13.28。振型的点估计不会相等（两类多出的
自由度不同），故不设 MAC 判据、只作参考打印；详见 `docs/VERIFICATION.md` 4.6 节与
`promote/HANDOFF.md` 第 7 节。`m = 1` 时 `S_11` 为实正标量、形状相位无处吸收，仍取
实形状。

### 3.8 接口层

`io_json.py` 与 `io_json.m` 读同一份描述、写同一套字段，三类描述（单测组、`multi_setup`、
`asynchronous`）按同一优先级取首个。多测组的自由度编号与异步的分组编号都从 0 起计，
两套实现共用该约定；MATLAB 读入时换算成 1 起计，输出时再还原。

统一输出形状时踩到三个真实缺陷，均已在 `matlab/+bayoma/` 修掉：

1. `struct('re', 元胞)` 会把元胞外层的花括号解开一层，实测 `struct("re",{{1,2}})`
   得 `{"re":[1,2]}` 而非 `[[1,2]]`；必须逐字段赋值 `value.re = …`。
2. 包内函数互相调用必须写全 `bayoma.` 前缀，否则报「未定义与 'double' 类型的输入参数
   相对应的函数」。
3. 字段判定只按末段会导致 `input.duration`、`input.fs` 这类嵌套标量字段被当成矩阵，
   输出 `[[900]]`；`to_json_tree` 递归时改为拼完整路径 `[field '.' names{i}]`，
   `is_scalar_field` / `is_flat_field` 再取末段判定。

最终方案是单点承担形状：`to_json_tree` 递归展开，`result_to_dict` 只搬运原生数组，
写盘前 `bayoma.encode_json(bayoma.to_json_tree(result))`。中途试过的 `num_list`、
`rows_list`、`json_rows`、`stack_list`、`json_ready` 五个辅助文件已删除。

### 3.9 第 16 章：Fisher 信息矩阵

第 15 章的定律已把 `ζ` 与 `S` 的相关性解析吸收进 `B_ζ`、`B_S`，因此单看五个边际值
无法还原四参数的相关结构。补 `uncertainty.py` / `uncertainty_matrix.m`：按表 16.2 直接
构造 4×4 Fisher 信息矩阵，求逆得后验协方差与相关矩阵。

两个易错点：

1. **符号**。式 (16.35) 的 `q_{ζS}` 是敏感度系数，取负值；由式 (16.34)–(16.36) 求逆得到
   的**后验**相关系数与之反号。`corr[1][2]` 与 `q_zeta_S` 不可混用，文档与技能里都写明了
   这一点，`test_tutorial_snippets.py` 的断言按后验相关系数的正号判。
2. **不重复实现一阶修正**。式 (16.43)–(16.44) 的 `c_xy/c` 与表 15.1 的 `α_x/c` 是同一
   修正的两种写法，两处同时施加会把修正计两次，因此第 16 章模块只做零阶与相关结构。

校核：表 16.2 求逆的边际值比表 15.1 小 0–1.6%（`S` 差最多），振型项完全一致；
表 16.4 的 `σ²_ζ`、`σ²_S` 闭式在四个 κ 下与矩阵求逆的相对差均小于 1e-15。

### 3.10 结果分组

结果组织层的扩充，不改识别模型与估计量。`results.py` 把已有输出重组为两组：

- `recognition`：频带与阶次对应（含代入计算的 `f0`）、密集模态区分度、联合后验协方差
  与逐行索引、逐阶振型不确定性、PSD/SV 谱、振型空间可视化；
- `assembly`：仅异步数据，组装后振型、识别与组装两个环节的不确定性分解、总后验协方差
  与索引、逐阶振型不确定性、空间可视化、组间相干矩阵。

四个实现要点：

1. **联合协方差是分块对角，不是近似**。不同识别频带的频点不重叠、负对数似然是各频带
   之和，Hessian 的跨频带交叉块严格为零，把各频带协方差沿对角线放置即联合协方差。
   因此跨频带相关系数恒为 0，做相关性分析只能取同一频带内的子块。
2. **振型不确定性在切空间计算后映回通道空间**。振型受单位范数约束，协方差只在单位球面
   切空间内有定义；用 `Z` 把切空间块 `C_θ` 映射回通道空间 `C_u = Z C_θ Zᵀ`，再取迹的
   平方根作为 `coefv`（与课本 11.3.3 节的定义一致）。复数振型按「实部在前、虚部在后」
   排布 `2n×2n`，逐通道方差取两块对角之和。
3. **识别与组装的不确定性用条件协方差分解**。把自由参数分成振型切坐标 `u` 与其余参数
   `θ`，`C_uu|θ = C_uu − C_uθ C_θθ⁺ C_θu` 是识别环节，`C_uθ C_θθ⁺ C_θu` 是组装环节，
   两者之和等于 `C_uu`。实测异步单阶算例两侧迹均为 3.883286e-04，可加性成立。
   `assembly_coefv` 占比过半说明不确定度主要来自测组之间相干矩阵的估计。
4. **命名可追溯**。阶次用 `order`、频带用 `band_index`、通道用 `channel_index`，全部
   从 0 起计；参数索引用 `name` 与 `index` 一一对应，矩阵任何一行都能追到参数、阶次与
   频带。图件文件名带阶次编号，与 `recognition.modes` 的 `order` 对应。

接口层新增三个关键字：`geometry`（通道位置、方向、连接，用于振型图）、`figure_dir`
（图件目录）、`spectra`（是否把谱写进结果）。三者缺省均不生成对应内容，`spatial` 会
给出 `available = false` 与原因，不报错。

新增自检 `python/tests/test_results.py`（四组共 60 项断言）与 `matlab/tests/test_results.m`
（82 项断言）。JSON 契约的形状在 MATLAB 侧另有两处专门处理：

- `to_json_tree` 把二维字段即使只有一个元素也写成数组的数组，与 Python 的
  `numpy.tolist()` 一致；该判定由 `is_matrix_field` 按字段名给出，复振型的 `re`/`im`
  按一维输出。
- `json_null` 的占位标记字段名取 `nul`，不能取 `__null__`：MATLAB 的结构体字段名必须
  是合法标识符，用带下划线的名字会在创建结构体时直接报错。

多阶异步结果的组装分组不再重复组间相干矩阵：契约里 `assembly.coherence` 是单个
`q × q` 复矩阵，多阶时该信息已在结果顶层以 `v12`、`v13` 等键给出。`check_matlab_schema.py`
正是靠这条校核发现该字段的形状冲突。

## 4. MATLAB 实现

逐函数对应 Python 侧，用 `fmincon`（有界）与 `fminunc` 代替 `scipy.optimize.minimize`。
**MATLAB 与 numpy 的差异导致的错误**：

1. `eig` 的第一个返回值是特征向量、第二个才是特征值（与 numpy 相反）。写反后协方差
   完全失真（`coefv.f = 5.85e8`）。
2. `fminunc` 只接受实变量。原先直接把复振型坐标传给优化器，虚部被丢弃，振型只能得
   实数。改为把实部与虚部拼成实向量，优化后再合回。
3. `diag(eig(M))` 返回矩阵而非向量，使 `[~, imax] = max(...)` 得到行向量并报维度错误。
4. 合成数据里 `Ek = (phi.*hk.')*S*(phi.*conj(hk).')'` 最外层的 `'` 是共轭转置，
   使 `Ek ≠ Ek^H`，谱矩阵量级错乱。改为 `(Ek + Ek')/2`。
5. 合成数据 `tdata = real(ifft(full)) * nt` 多乘了 `N`，功率放大 `N²`（`D` 的对角均值
   达 6.96e9，应为 `Se = 1`）。去掉该因子后回到 1.93。
6. `jsondecode` 把 `[[0.9,1.1]]` 解成 2×1 列向量，需按「每行一个频带」还原。

## 5. 交叉校核

每一步都用同一份数据在两套实现上跑一遍，比较最可能值与后验变异系数：

- 单模态：频率、阻尼比、模态力谱、噪声谱相对差小于 1e-6，五个参数的变异系数相对差
  均小于 1e-4。
- 多模态：同一份 Python 生成的数据，两侧最可能值一致到 1e-5。
- 多测组：单测组时多测组实现与单模态实现逐位一致；四测组联合识别的全局振型 MAC 0.99999。
- 接口层：同一份四测组描述文件，两侧结果一致到 1e-4，协方差矩阵同为 21×21。

## 5.1 现场实测数据

合成数据的幅值、谱密度都在 `S = 1`、`Se = 1` 的量级，覆盖不到真实记录的量级。改用
pcode 附带的现场数据（12 通道、1800 s、64 Hz、以 g 计、幅值 1e-2 g 量级）复跑，暴露出
两个合成数据上不会出现的缺陷：

1. **逐阶输出长度不一致**。总入口原按频带取模态力谱矩阵的第一个对角元拼 `Sii`，而
   `f`、`z` 按阶拼。一个频带含两阶模态时（该数据第 1、4 个频带都是两阶），`rms` 的
   计算报 `operands could not be broadcast together with shapes (4,) (6,)`。改为逐阶取
   对角元。
2. **后验协方差在谱参数量级极小时退化为零**。该数据的 `S`、`Se` 为 1e-11 量级，振型
   分量为 1e-1，解析 Hessian 的对角元相差 10 个数量级；`pinv` 的相对容差 1e-12 把
   小量级方向判成零曲率，`f`、`z`、`phi` 的变异系数全部为 0（`S`、`Se` 正常）。改为
   先按对角元做雅可比预条件再求逆，两套实现同步修正。

为防这类缺陷复发，Python 自检新增尺度不变性一项：把同一份合成记录整体乘 1e-5，要求
频率、阻尼比与各参数变异系数的相对变化在 1e-4 以内。用 `S = 1` 的常规算例不会暴露
第 2 类缺陷，只有改变量级才会。

现场数据的核对写在 `python/tests/test_field_data.py`，因为依赖外部数据目录，未并入自检。
