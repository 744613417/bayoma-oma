# 输入输出规范

本规范同时适用于 Python 的 `bayoma.bayoma` 与 MATLAB 的 `bayoma.bayoma`，两者的
字段名、单位、缺省值完全一致。JSON 接口层（`bayoma.io_json`）在两侧也使用同一份
字段定义。

## 1. 输入

### 1.1 必填字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `tdata` | `nt × nch` 实数矩阵 | 环境振动记录，行对应时刻、列对应通道 |
| `fs` | 正实数 | 采样频率，单位 Hz |
| `f1f2` | `nb × 2` 实数矩阵 | 识别频带的上下界，每行一个频带，单位 Hz |
| `f0` | 长度 `nb` 的序列，每项为一维数组 | 各频带内固有频率的初值，单位 Hz |

`f1f2` 与 `f0` 缺省时按奇异值谱自动选带，此时频带数与频带内的模态数由自动选带
判定，`f0` 取各频带的主峰。

### 1.2 可选字段

| 字段 | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `mute` | 0 或 1 | 0 | 1 表示不输出中间信息，0 表示输出 |
| `ichan` | 整数序列 | 全部 | 参与计算的通道索引（1 基） |
| `iband` | 整数序列 | 全部 | 参与计算的频带索引（1 基） |
| `maxiter` | 正整数 | 500 | 最可能值迭代的上限 |
| `f1f2d` | `nd × 2` 实数矩阵 | 空 | 需从似然函数排除的频带 |
| `p` | 标量或长度 `nch` | 0 | 原始数据第 `i` 通道乘以 `(i·2πf)^{p_i}` 的指数 |
| `q` | 标量 | 0 | 模态频响函数除以 `(i·2πf_k)^q` 的指数 |

`p` 与 `q` 的含义是数据类型的换算：原始数据为加速度时 `p = 0`，速度时 `p = 1`，
位移时 `p = 2`；模型侧的派生数据为加速度时 `q = 0`，速度时 `q = 1`，位移时 `q = 2`。

### 1.3 数据类型的模型

设原始记录经 `p` 换算后得到派生数据，则第 `k` 个频率点上的缩放的快速傅里叶变换
满足

```
派生数据的缩放 FFT = Σ_modes [振型 × 模态频响 / (i·2πf_k)^q × 模态力] + 通道噪声
```

通道噪声在各通道之间独立同分布，在选定频带内为常值的限带白噪声，其单边谱密度
记为 `Se`。

### 1.4 异步数据的输入

当同一测组内部分通道之间不同步采集时（例如多套采集仪器未共用时钟），按课本第
10.4 节改用异步模型。输入为

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `freqs` | `1 × Nf` | 频带内的频率坐标，单位 Hz |
| `fft` | `n × Nf` 复矩阵 | 缩放 FFT，保留复值 |
| `groups` | 列表的列表 | 测组划分，`groups[r]` 为第 r 组各通道的索引 |

异步模型额外估计组间复相干矩阵 `v`（`q × q`，Hermitian、对角元为 1），各测组
有各自的预测误差谱密度 `S_er`。`groups` 必须互不重叠且覆盖全部通道；`q = 1` 时
退化为第 12 章的同步单模态问题。

### 1.5 异步数据多阶模态的输入

频带内有多阶模态时，接口再增加一个字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `n_modes` | 整数 | 频带内的模态阶数 `m`，缺省 1 |

模型按式 (10.47) 把单阶的 `S·D_k·ũ·v·ũᵀ` 推广为双重求和
`Σ_i Σ_j h_ik h*_jk S_ij (U_i V_ij U_jᵀ)`，其中 `U_i = blockOp(u_i, groups)` 只在本组
行块上非零，`V_ij` 为第 i 阶与第 j 阶之间的 `q × q` 相干矩阵。各阶共用同一组测组
划分与同一振型矩阵，但各有独立的频率、阻尼比与相干矩阵。

参数规范：`ng = 1` 时 `V` 不存在，`S_ij` 的复相位可辨识，`S` 取 Hermitian 复矩阵；
`ng ≥ 2` 时相位由 `V_ij` 承担，`S` 取实对称。调用方不必区分，两套实现内部按
测组数自动切换。

`ng = 1` 且 `m > 1` 时模态形状取复向量（第 13 章的复模态形状），`phi` 因而为复矩阵；
`ng ≥ 2` 时形状取实向量（相位由 `V_ij` 承担）。JSON 输出中复矩阵按
`{"re": …, "im": …}` 序列化，实矩阵按列表序列化，调用方按 `phi` 的类型判断即可。
`m = 1` 时 `S_11` 为实正标量、形状相位无处吸收，形状仍为实向量。

## 2. 输出

### 2.1 最可能值

| 字段 | 形状 | 单位 | 说明 |
| --- | --- | --- | --- |
| `f` | `1 × m` | Hz | 各阶固有频率 |
| `z` | `1 × m` | 无量纲 | 各阶阻尼比 |
| `Sii` | `1 × m` | 数据单位²/Hz | 各阶模态力自谱（单边） |
| `Se` | `1 × m` | 数据单位²/Hz | 各阶通道噪声谱（单边） |
| `phi` | `nch × m` | 无量纲 | 振型，每列一阶，欧氏范数为 1 |
| `rms` | `1 × m` | 数据单位² | 模态加速度均方根，`sqrt(π·Sii·f/(4·z))` |
| `S` | 长度 `nb` 的序列 | 数据单位²/Hz | 各频带的模态力谱矩阵（Hermitian），单模态时为标量 |

### 2.2 后验不确定性

| 字段 | 形状 | 说明 |
| --- | --- | --- |
| `coefv` | 结构体 | 各参数的变异系数：`f`、`z`、`Sii`、`Se`、`phi`、`rms` |
| `cmat` | 长度 `nb` 的序列 | 各频带的无量纲参数协方差矩阵 |

`cmat` 的排列顺序为

```
[f, z, diag(S), Re(offdiag S), Im(offdiag S), Se, phi]
```

除 `phi` 外各参数均按最可能值归一，故对角线元素直接是变异系数的平方。
`coefv.phi` 按课本 11.3.3 节的定义给出，即振型后验协方差矩阵各特征值平方根之和，
与协方差矩阵迹的平方根等价。

### 2.3 其它输出

| 字段 | 形状 | 说明 |
| --- | --- | --- |
| `sn` | `1 × m` | 模态信噪比，`Sii/(4·Se·z²)` |
| `time_req` | `2 × nb` | 各频带求最可能值与后验协方差的耗时，单位 s |
| `bands` | `nb × 2` | 实际使用的识别频带 |
| `nch` | 标量 | 参与计算的通道数 |
| `fs` | 标量 | 采样频率 |

## 3. 单位约定

- `tdata` 以重力加速度 g 为单位时，`Sii`、`Se`、`S` 的单位是 g²/Hz，`rms` 的单位是 g²。
- `z`、`sn`、`coefv` 全为无量纲量。
- `phi` 每列的欧氏范数为 1，正负号按该列绝对值最大的分量为正实数确定。
- `Sii`、`Se`、`S` 均为单边谱。

## 4. 自动选带

`f1f2` 缺省时按以下步骤选带：

1. 用 Welch 平均法估计样本谱密度矩阵，避免单次实现的谱矩阵秩为 1 使高阶奇异值为 0；
2. 计算奇异值谱（按降序排列的各阶特征值曲线）；
3. 取最高阶曲线的全频段中位数作为噪声基线；
4. 在第 1 条奇异值曲线的滑动平均上检测峰值，同时满足两个判据：高于噪声基线
   `peak_factor` 倍（缺省 5），且不低于最高谱峰的 `rel_peak` 比例（缺省 0.05）；
5. 每个峰给一个频带，半宽取 `kappa × 0.01 × f`，相邻频带按中点切开；
6. 在峰处统计显著高于噪声基线的奇异值曲线条数，作为该频带的模态数。

第 4 步的两个判据缺一不可。仅用噪声基线时，宽带噪声的起伏可高出基线数十倍却远低于
真实共振峰（实测噪声起伏可达基线的 25 倍、真实峰值的 1%–2%），会被误判成模态；
仅用相对最高峰的比例时，孤立的小峰可能漏判。`rel_peak` 的缺省值 0.05 在合成数据上
把噪声起伏（1%–2%）与真实共振峰（68% 以上）分开。

自动选带的输出写入 `bands`，模态数决定该频带走单模态还是多模态分支。

## 5. 失败情形

| 情形 | 表现 |
| --- | --- |
| 数据不是二维矩阵 | 抛出参数错误，提示行对应时刻、列对应通道 |
| 采样频率非正 | 抛出参数错误 |
| `f0` 长度与频带数不一致 | 抛出参数错误 |
| 排除频带后没有剩余频率点 | 抛出参数错误 |
| 频带内模态数大于等于通道数 | 部分参数不可辨识，`Se` 的最可能值可能落在 0，`sn` 与 `Se` 的结果不可用，其余参数受影响较小 |
| 模态力谱矩阵部分不可辨识 | 最可能值收敛慢或达到迭代上限，`S` 的后验变异系数可能大于 100%，提示存在无法分辨的密集模态 |
| 识别失败 | JSON 接口返回非零退出码，标准错误给出原因 |

## 6. JSON 接口字段

### 6.1 描述文件

```json
{
  "data": {"path": "data.csv", "format": "csv", "fs": 100.0,
           "delimiter": ",", "skip_header": 0, "key": "tdata"},
  "fs": 100.0,
  "bands": [[0.9, 1.1]],
  "f0": [[1.0]],
  "options": {"q": 0, "p": 0, "maxiter": 500, "mute": 1,
              "ichan": null, "iband": null, "f1f2d": null},
  "multi_setup": {"n_dof": 6,
                  "setups": [{"data": {"path": "s1.csv", "fs": 100.0},
                              "dofs": [0, 1, 2], "bands": [[2.9, 3.1]]}]},
  "asynchronous": {"data": {"path": "async.csv", "fs": 100.0},
                   "groups": [[0, 1], [2, 3]],
                   "bands": [[0.9, 1.1]], "f0": [1.0], "q": 0},
  "output": {"path": "result.json"}
}
```

`data.format` 取 `csv`、`npy`、`mat` 之一，缺省按扩展名推断；`txt`、`dat` 按 `csv`
处理。`data.key` 只在 `mat` 格式下使用。

多测组描述中，`dofs` 采用从 0 起计的自由度编号，`n_dof` 为全局自由度数；两套实现
共用同一编号约定，MATLAB 内部按 1 起计并在读入时换算。每个测组条目必须给出 `bands`。

异步数据描述（课本 10.4 节）中，`groups` 为测组划分，每项是同步采集的通道索引列表，
组内同步、组间不同步，`groups` 必须互不重叠且覆盖全部通道。识别给出组间复相干矩阵
`coherence` 与逐组的预测误差谱密度 `Se`。`f0` 与 `q` 可选，`f0` 缺省取奇异值谱峰。

`n_modes` 指定频带内的模态阶数，缺省 1；`n_modes > 1` 时走第 10.4 节的多阶模型，
各阶对另给出独立的相干矩阵 `coherence`（字段 `v12`、`v13` 等）。此时 `S` 的规范
随测组数变化：单测组时取 Hermitian 复矩阵（`S_ij` 的相位可辨识），多测组时取实对称
（相位由相干矩阵承担）。`f0` 给出时其长度应与 `n_modes` 一致。
三类描述（单测组、`multi_setup`、`asynchronous`）互斥，同时出现时按
`asynchronous` → `multi_setup` → 单测组的顺序取首个。

### 6.2 结果文件

结果文件包含第 2 节的全部字段，另加

| 字段 | 说明 |
| --- | --- |
| `input` | `fs`、`nch`、`nt`、`duration`，记录的基本信息；多测组结果另含 `n_setup`，异步数据结果另含 `n_group` |
| `n_modes` | 模态总数 |
| `elapsed` | 总耗时，单位 s |
| `groups` | 仅异步数据结果：测组划分 |
| `coherence` | 仅异步数据结果：组间复相干矩阵，按 `{"re": …, "im": …}` 给出 |

复数矩阵按 `{"re": …, "im": …}` 形式给出，两套实现一致。异步数据结果的 `coefv`
另含 `v`，为相干矩阵非对角元方差之和的平方根。

## 7. 机器可读契约

除本文件的人读说明外，接口的形状由 `schema/` 下两份 JSON Schema 给出，供其他软件或
智能体直接校验，不必先解析本文件。

| 文件 | 描述对象 | 用途 |
| --- | --- | --- |
| `schema/job.schema.json` | 任务描述文件 | 提交给 `bayoma.io_json` 的描述是否合法 |
| `schema/result.schema.json` | 结果文件 | 识别输出是否满足契约（字段齐全、形状正确） |

两份都是 JSON Schema 2020-12，顶层 `additionalProperties` 为 `false`，即出现未定义字段
会被判为不合法。

### 7.1 描述文件的结构要点

`anyOf` 要求三类测量描述至少出现一个：`multi_setup`、`asynchronous`，或同时给出
`data` 与 `bands`（单测组同步数据）。`bands` 的每项长度必须恰为 2，`f0` 的外层长度
等于频带数、内层每个初值必须为正。`options.q` 与 `options.p` 只接受 0、1、2，分别对应
加速度、速度、位移。多测组的 `dofs` 从 0 起计，异步数据的 `groups` 每项至少 2 个通道
——单个通道的测组无法估计组间相干。

### 7.2 结果文件的形状规则

同一字段在三种识别路径下形状一致，这是 Python 与 MATLAB 两侧统一后的结果：

- `f`、`z`、`Sii`、`Se`、`rms`、`sn` 一律一维数组，长度等于模态总数，即使只有一阶也
  写成 `[x]` 而不是 `x`；
- `phi` 一律二维：单测组为通道数 × 阶数，多测组为全局自由度数 × 阶数；单测组异步多阶
  给出复振型，按 `{"re": …, "im": …}` 写两个同形状的二维数组；
- `bands` 为频带数 × 2，`S` 与 `cmat` 为按频带的数组（`S` 的元素是矩阵或 `{"re","im"}`，
  单模态频带下退化为数字）；
- `coefv` 的每一项沿用上述形状（标量参数写一维数组，`S_off` 与 `v` 为复数时写
  `{"re","im"}`）；
- `input` 内的 `fs`、`nch`、`nt`、`duration` 是数字，多测组另加 `n_setup`、异步数据另加
  `n_group`。

MATLAB 的 `jsonencode` 无法区分标量与长度 1 的数组，因此 MATLAB 侧写盘前先经
`bayoma.to_json_tree` 把形状显式化，再由 `bayoma.encode_json` 生成与 `json.dumps`
一致的文本。两侧产物对同一份 schema 校验：同步单阶、同步多阶、多测组、异步单阶、
异步多阶均为 0 错误。

### 7.3 校验方式

```powershell
cd bayoma-oma
python python\tests\test_schema.py
```

该脚本先校验两份 schema 自身可用，再对三条反例断言被拒（缺测量描述、单通道测组、
结果缺必需字段），最后对四类真实算例逐个走「描述过 schema → 识别 → 结果过 schema →
结果文件可读回」，共 17 项。依赖 `jsonschema`，未安装时脚本跳过校验并提示，不判为失败。

其他语言只需读两份 JSON 文件即可，例如 MATLAB 可用 `jsondecode` 读 schema，但校验器
需自备；Python 一行即可：

```python
import json, jsonschema
schema = json.load(open("schema/result.schema.json", encoding="utf-8"))
jsonschema.validate(result, schema)   # 不合法时抛 ValidationError
```

## 8. 结果分组：识别结果与组装结果

结果文件在基础字段之外增加两个分组，字段名分别是 `recognition` 与 `assembly`。
两者都只依赖已有输出，不改变识别模型与估计量，属于结果组织层的扩充。

| 分组 | 出现条件 | 内容 |
| --- | --- | --- |
| `recognition` | 总是给出 | 频带与阶次的对应、密集模态区分度、参数联合后验协方差与索引、逐阶振型不确定性、谱图数据、振型空间可视化 |
| `assembly` | 仅异步数据识别 | 组装后振型、识别不确定性与组装不确定性的分解、最终后验协方差与索引、逐阶振型不确定性、空间可视化、相干矩阵 |

`assembly` 之所以只对异步数据给出：异步模型把同一阶模态在不同测组之间的相对幅值与
相位写成相干矩阵，组装环节的输入不确定性（各测组内的识别结果）与输出不确定性
（组装后的全局振型）是两个可分离的来源，才需要单独量化。同步识别与多测组识别的
全局振型在似然函数内部一次求出，不存在独立的组装环节。

### 8.1 `recognition` 分组的字段

| 字段 | 形状 | 说明 |
| --- | --- | --- |
| `bands` | 对象数组 | 每个识别频带一项：`band_index`、`lower`、`upper`、`bandwidth`、`n_modes`、`f0`（代入计算的频率初值），自动选带时另含 `peak`，被排除的频带另含 `excluded` |
| `modes` | 对象数组 | 每一阶模态一项：`order`（全局阶次，从 0 起计）、`band_index`、`order_in_band`、`frequency`、`band_lower`、`band_upper`、`f0` |
| `separation` | 对象 | 密集模态区分度，见 8.2 节 |
| `joint_covariance` | 对象 | 联合后验协方差的元信息：`index`（参数描述数组）、`size`、`structure`、`note` |
| `joint_covariance_matrix` | 二维数组 | 联合后验协方差矩阵本身，行列顺序与 `index` 一致 |
| `shape_uncertainty` | 对象数组 | 每一阶模态一项：`order`、`complex`、`coefv`、`channel_index`、`std_per_channel`、`ci95_halfwidth_per_channel`、`shape`、`cov` |
| `spectra` | 对象或 `null` | 时程数据的 PSD 谱与 SV 谱，仅 `spectra` 开关打开时给出，见 8.4 节 |
| `spatial` | 对象或 `null` | 振型空间可视化，仅给出通道几何时生成图件，见 8.5 节 |

`joint_covariance.index` 的每一项至少含 `index`（在矩阵中的行列号，从 0 起计）、
`name`（参数名，例如 `f[0]`、`z[1]`、`S[0][1]`、`Se`、`phi[0].theta[3]`）、
`kind`（参数类别：`f`、`z`、`S_diag`、`S_off_re`、`S_off_im`、`S_off`、`Se`、
`phi_tangent`、`phi_component`、`v_re`、`v_im`、`v_mod`、`v_phase`）、
`symbol`（符号）与 `unit`（单位）。跨频带的参数按频带顺序连续编号，`band_index`
给出该参数所属频带。

各 `kind` 的含义：`S_diag` 是模态力谱矩阵的对角元；`S_off_re`、`S_off_im` 是实振型
情形下非对角元的实部与虚部，`S_off` 是异步多阶在 `S` 取实时的非对角元（单个实值）；
`phi_tangent` 是振型在单位球面切空间内的坐标；`phi_component` 是单模态频带直接按
通道列出的振型分量；`v_re`、`v_im` 是组间相干矩阵元的实部与虚部，`v_mod`、`v_phase`
是异步多阶按模与相位参数化的相干元。

联合协方差是分块对角结构：不同识别频带的频点不重叠，负对数似然是各频带之和，故
Hessian 关于「频带内参数」与「其它频带参数」的交叉块为零，联合协方差就是把各频带的
协方差按频带顺序沿对角线放置。这是似然可加性的直接推论，不是近似。因此跨频带的
参数相关系数恒为 0，只有同一频带内的参数之间存在相关性。

### 8.2 密集模态区分度

`separation` 用「频率间隔与半功率带宽之比」判定两阶模态是否密集：

```
separation_in_bw = |f_i - f_j| / max(2 z_i f_i, 2 z_j f_j)
```

分母取两阶中较宽的那个半功率带宽。`separation_in_bw < 2` 时判为密集模态
（阈值 `threshold = 2.0`）。字段构成：

| 字段 | 说明 |
| --- | --- |
| `criterion` | 判据的文字说明 |
| `threshold` | 阈值 2.0 |
| `pairs` | 对象数组，每一对同频带模态一项：`modes`（两个全局阶次）、`band_index`、`df`、`half_power_bw`、`separation_in_bw`、`dense`（布尔）、`mac`（两阶振型的模态置信因子）、`f_correlation`（两阶频率的后验相关系数，取自联合协方差） |
| `dense_pairs` | 被判为密集的阶次对列表 |
| `has_dense_modes` | 是否存在密集模态对 |

`mac` 用振型内积计算：实数振型取 `|φ_i^T φ_j|² / (‖φ_i‖²‖φ_j‖²)`，复数振型取
`|φ_i^H φ_j|² / (‖φ_i‖²‖φ_j‖²)`。`f_correlation` 用于判断两阶频率的估计是否
在统计上可分：相关系数接近 ±1 而区分度小于 1 时，两阶频率实际不可分辨。

### 8.3 逐阶振型的识别不确定性

`shape_uncertainty` 逐阶给出振型的后验不确定性，用于判断振型是否可靠、哪些通道的
分量最不确定。振型受单位范数约束，其协方差只在单位球面的切空间内有定义；本实现
用切空间参数化直接给出通道空间的协方差：

| 字段 | 说明 |
| --- | --- |
| `order` | 全局阶次 |
| `complex` | 振型是否为复数（第 13 章复模态形状、异步单测组多阶） |
| `coefv` | 振型的变异系数，定义为通道空间协方差矩阵迹的平方根（课本 11.3.3 节） |
| `channel_index` | 通道编号，从 0 起计 |
| `std_per_channel` | 逐通道分量的后验标准差；复数振型取实部与虚部方差之和 |
| `ci95_halfwidth_per_channel` | 逐通道的 95% 置信半宽，取 1.96 倍标准差 |
| `shape` | 该阶振型本身，便于与标准差逐通道对照 |
| `cov` | 该阶振型在通道空间的协方差矩阵；复数振型按「实部在前、虚部在后」排布 |

### 8.4 PSD 谱与 SV 谱

`spectra` 在 `spectra` 开关打开时给出，用于核对识别所用频带与频率初值是否合理。
谱由 Welch 平均得到（分段 Hann 窗、50% 重叠），SV 谱是各频率点平均谱矩阵的特征值
按降序排列。

| 字段 | 说明 |
| --- | --- |
| `freqs` | 频率坐标（Hz），一维数组 |
| `psd_diag` | 各通道的自谱，二维数组：每行一个通道 |
| `sv` | 奇异值谱，二维数组：每行一条奇异值曲线（第 0 行为最高阶） |
| `stride` | 抽稀步长 |
| `n_freq_full` | 抽稀前的频率点数 |
| `n_freq_kept` | 抽稀后的频率点数 |
| `reduction` | 抽稀方式，取「块内平均」 |
| `bands` | 对象数组，每个识别频带一项：`band_index`、`lower`、`upper`、`f0`（代入计算的频率初值）、`n_freq_points`、`peak_freq`（该频带内 SV 最高阶曲线的峰频） |
| `note` | 说明文字 |

抽稀只在写盘时进行，识别本身始终用全部频点。默认上限为 1024 点，避免结果文件
因长记录而过大。

### 8.5 振型空间可视化

给出通道几何（位置、方向、连接）后，逐阶生成振型图。几何在描述文件中的写法：

```json
"geometry": {
  "channels": [
    {"name": "ch1", "position": [0.0, 0.0, 0.0], "direction": [1.0, 0.0, 0.0]},
    {"name": "ch2", "position": [0.0, 0.0, 0.6], "direction": [1.0, 0.0, 0.0]}
  ],
  "connections": [[0, 1]]
}
```

`position` 与 `direction` 都是长度 3 的数组，`direction` 必须非零（内部归一化后
使用）。`connections` 给出需要连线的通道对，用于把测点连成结构轮廓。`channels`
的长度必须等于参与识别的通道数，`name` 可选。

图件写在描述文件的 `figures.dir` 指定的目录下：

| 分组 | 文件名 |
| --- | --- |
| `recognition.spatial` | `mode_00.png`、`mode_01.png`……按全局阶次编号 |
| `assembly.spatial` | `assembly_00.png`、`assembly_01.png`…… |

每张图包含未变形的虚线轮廓与按振型缩放后的变形实线，散点按该阶分量的幅值着色。
复数振型画两栏，左为实部、右为虚部。

未给出几何或未指定 `figures.dir` 时，`spatial` 仍给出通道几何与振型数据，但
`available` 为 `false`，`reason` 说明原因：

| 字段 | 说明 |
| --- | --- |
| `available` | 是否生成了图件 |
| `reason` | 未生成时的原因；生成时为 `null` |
| `channel_names` | 通道名称，未给出时用通道编号 |
| `connections` | 连接对 |
| `figures` | 生成的文件路径列表 |

### 8.6 `assembly` 分组的字段（仅异步数据）

| 字段 | 说明 |
| --- | --- |
| `phi` | 组装后的全局振型，通道数 × 阶数；复振型按 `{"re","im"}` 给出 |
| `channel_index` | 通道编号，从 0 起计 |
| `shape_uncertainty` | 组装后振型的不确定性，结构同 8.3 节，另含 `per_mode`（逐阶） |
| `uncertainty` | 不确定性的分解，见下 |
| `posterior_covariance` | 组装后的后验协方差矩阵（总不确定性对应的矩阵） |
| `covariance_total` | 同上，便于与两个分量对照（可能省略） |
| `covariance_from_assembly` | 组装环节贡献的协方差块 |
| `covariance_recognition` | 识别环节贡献的协方差块 |
| `index` | 参数描述数组，行列顺序与上述矩阵一致 |
| `setups` | 测组划分，每项含 `group_index` 与 `channels` |
| `coherence` | 组间复相干矩阵，按 `{"re","im"}` 给出 |
| `spatial` | 组装后振型的空间可视化，结构同 8.5 节 |

`uncertainty` 的字段：

| 字段 | 说明 |
| --- | --- |
| `method` | 分解方法的文字说明 |
| `total_coefv` | 组装后振型的变异系数（总不确定性） |
| `assembly_coefv` | 组装环节引入的变异系数分量 |
| `recognition_coefv` | 识别环节带来的变异系数分量 |
| `trace_total`、`trace_assembly`、`trace_recognition` | 对应的协方差矩阵迹 |
| `note` | 说明文字 |

分解按条件协方差计算。设振型切空间坐标为 `u`、其余自由参数（各测组的频率、阻尼比、
谱密度、相干矩阵元）为 `θ`，全协方差为 `C`，则

```
C_uu|θ = C_uu - C_uθ C_θθ^+ C_θu
```

`recognition_coefv` 由 `C_uu|θ` 给出，`assembly_coefv` 由 `C_uθ C_θθ^+ C_θu`
的迹给出，两者之和等于 `total_coefv` 的平方（数值上相等，已在校核中确认）。
含义是：若其余参数完全已知，振型还剩多少不确定性，属于识别环节；其余参数的不确定性
经相关性传递到振型的部分，属于组装环节。

### 8.7 命名与追溯约定

新增字段全部按「分组 → 参数 → 阶次/通道/频带」的层级组织，命名规则如下：

- 阶次一律用 `order`，从 0 起计，按频率升序；`band_index` 为该阶所属频带，从 0 起计；
- 通道一律用 `channel_index`，从 0 起计，与输入数据的列顺序一致；
- 频带一律用 `band_index` 与 `lower`/`upper` 成对给出；
- 参数索引项用 `name` 指明参数、用 `index` 指明在矩阵中的行列号，两者一一对应，
  矩阵任何一行都能追到具体参数、模态阶次与频带；
- 谱图数据的 `bands` 与 `recognition.bands` 用同一套 `band_index`，可直接对照；
- 图件文件名带阶次编号，与 `recognition.modes` 的 `order` 对应。
