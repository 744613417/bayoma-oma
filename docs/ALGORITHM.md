实现要点：

1. 似然函数的二次型必须用复值投影 `F'_k = B₀ᵀ·F_k`，不能先把 `F_k·F_k^*` 取实部。
   用实部会丢掉互谱的虚部，模态力谱矩阵的非对角元失去约束，实测估计值偏离真值。
2. 模态形状的复相位不可辨识（`u_i → u_i·e^{iθ}` 时似然不变，相位差被 `S` 吸收），
   因此输出前必须对 `phi`、`alpha`、`S` 三者同步施加同一相位变换，否则三者不再满足
   `phi = B₀·alpha`，用不同字段计算似然会得到不同结果。
3. 初始子空间基只覆盖一个子空间，密集模态下真实解可能转出该子空间。实现中用
   式 (13.22)–(13.23) 的 Givens 超角做联合精化，参数向量扩为
   `[谱参数, 振型坐标, 超角]`。
4. 各阶模态在输出前按频率升序重排，`phi`、`alpha`、`S` 同步重排。

| 全局最小二乘的迭代 | 14.2.3 节，p435（427） |

实现要点：

1. 似然的最后一项必须整段相减后再除以 `Se`，即
   `(d̂^(r) - Σ_k B_k·q_k)/Se^(r)`，不能逐频率除以 `Se`。
2. 更新顺序为：先由各测组解子问题得 `{f, z, S₀, Se}`，再由式 (14.41) 算 `λ_r`，
   然后构造 `B` 取最小特征值特征向量得 `u`，最后用式 (14.37) 更新 `c_r`。
   若先构造 `B` 再算 `λ_r`，首轮乘子为零，`B` 只剩负定项，全局振型会落到无物理
   意义的方向。
3. 输出时按式 (14.27) 反算 `S^(r) = S₀^(r)/‖t_r‖²`。
4. 多测组的每个测组的谱参数独立，全局振型共用。
5. 全局振型缺省在参考自由度凝聚子空间内求解（`condense` 选项，缺省开启）。
   参考自由度指被两个以上通道测到的自由度，`L_c` 的前若干列取参考自由度的单位向量，
   其余列取各测组非参考自由度方向的单位向量，满足 `L_cᵀL_c = I`。凝聚后待求向量维数
   由自由度总数降到 `n₀₀ + n₀ + n`，式 (14.20) 的特征值问题相应降到 `2n₀×2n₀`。
   后验协方差仍在完整的 n 维切空间内计算，与凝聚维数无关。
6. 全局最小二乘迭代中必须每轮把各测组局部振型的正负号对齐到 `t̃_rᵀL_r u > 0`。
   局部振型的整体符号不可辨识，不作对齐时迭代收敛到错误驻点（课本 Example 14.2 实测
   MAC 仅 0.41）。

## 8. 异步数据（`asynchronous.py` / `asynchronous_single_mode.m`）

| 内容 | 课本位置 |
| --- | --- |
| 缩放 FFT 的分块模型 | 式 (10.44)–(10.46)，p340–341（332–333） |
| 组间相干因子 `v_ijrs` 及其约束 | 式 (10.45)，p341（333） |
| 谱矩阵 `E_k = S·D_k·ũ·v·ũᵀ + diag{S_er·I_nr}` | 式 (10.47)–(10.50)，p341–343（333–335） |
| 单模态的参数集与相干矩阵 | 10.4.2 节，p343（335） |
| 负对数似然函数 | 式 (10.42)，p340（332） |

实现要点：

1. 式 (10.42) 的行列式与二次型按 `E_k = D₀^{1/2}(I + S·D_k·M)D₀^{1/2}` 改写，
   `M = D₀^{-1/2}(ũ·v·ũᵀ)D₀^{-1/2}` 为秩不超过 `q` 的 Hermitian 半正定矩阵。对 `M`
   作一次特征分解，两项求和都化为 `n` 个标量的累加，单次似然评估为 `O(n²N_f)`，
   与逐频率直接求逆的结果相差 4.4e-16。
2. `M` 在 MATLAB 侧必须用 `triu(M) + triu(M,1)'` 强制精确 Hermitian。先作
   `(M+M')/2` 后 `ishermitian` 仍可能返回假，`eig` 走一般矩阵分支，特征向量不正交，
   特征分解式失效，实测负对数似然偏高约 140、相干矩阵模的误差达 0.06。
3. 局部振型的整体符号不可辨识：`t_r → -t_r` 同时把相干矩阵第 `r` 行与第 `r` 列反号，
   谱矩阵不变。输出统一取「绝对值最大的分量为正」的符号约定。
4. 谱密度参数的优化边界按数据量纲取（`d_scale = mean|F_k|²`，上下界取
   `d_scale·1e±8`）。改用与数据无关的 `1e-30~1e30` 时，有界拟牛顿法的线搜索在初值处
   即报告相对下降收敛，谱参数子问题不再前进。
5. 后验协方差的自由参数取 `[f/f̂, z/ẑ, S/Ŝ, {S_er/Ŝ_er}, θ, {Re δv_ij, Im δv_ij}]`，
   模态形状用切空间参数化，谱参数按最可能值无量纲化。
6. 合成数据沿用频域法，谱矩阵取式 (10.50) 并显式对称化。用 `q = 1` 的合成数据可
   把异步实现退化到第 12 章的同步单模态，作为正确性判据：实测 `f`、`z`、`S`、`Se`
   的相对差在 1.8e-5 以内，振型 MAC 为 1.0000000000。

## 8.1 异步数据的多阶模态（`asynchronous_multi.py` / `asynchronous_multi_mode.m`）

| 内容 | 课本位置 |
| --- | --- |
| 多阶谱矩阵 `E_k = Σ_i Σ_j h_ik h*_jk S_ij (U_i V_ij U_jᵀ) + D₀` | 式 (10.47) 的推广 |
| 紧凑形式 `E_k = G W_k S_v W_k^* G^T + D₀` | 式 (10.48) |
| 相干矩阵的 Hermitian 约束与对角元 | 式 (10.45)、(10.51) |
| 负对数似然函数 | 式 (10.42) |

实现要点：

1. **降维恒等式**。取 `G = [U_1, …, U_m]`（`n × mq`）的列空间正交基 `B`（`n × m₀`），
   记 `A = B^T G`、`Bt = D₀^{-1/2} B`、`H = Bt^T Bt`、`E0_k = A W_k S_v W_k^* A^T`，则
   `ln|E_k| = Σ_r n_r ln Se_r + ln det(I + E0_k H)`、
   `F_k^* E_k^{-1} F_k = |D₀^{-1/2} F_k|² − G_k^*(E0_k^{-1} + H)^{-1} G_k`，
   其中 `G_k = Bt^T D₀^{-1/2} F_k`。两式都化为同一个 `m₀ × m₀` Hermitian 正定矩阵
   的 Cholesky 分解，单次评估为 `O(N_f m₀³)`，与逐频率 `n × n` 求逆的相对差为
   1.6e-15。
2. **二次型的数值形式**。谱值比真实值大若干量级时，`Y^T E0 Y` 与回代项都达 `1e+13`
   而两者之差只剩 1，直接相减丢掉全部有效位（实测出现 `-5.5e+11` 的伪极小值，
   优化器随即停在参数边界）。改用等价形式 `q_k = |y_k|² − |g_k|² + g_k^* Q_k^{-1} g_k`，
   其中 `g_k = H^{-1/2} Y_k`、`Q_k = I + H^{1/2} E0_k H^{1/2}`；`|y_k|² − |g_k|²` 与频率
   无关只算一次，两项都随谱值增大单调趋向有限值，不发生大数相消。
3. **模态力谱矩阵的规范随测组数变化**。`ng ≥ 2` 时 `S_ij` 的相位与 `V_ij` 的整体
   相位是同一规范自由度，取 `S` 实对称即固定该规范；若改取复 Hermitian，Hessian
   沿该方向曲率为零，后验方差发散。`ng = 1` 时 `V` 不存在，`S_ij` 的复相位是可辨识
   参数，必须取 Hermitian 复矩阵，否则模型受限：实测单测组两阶问题比同步多阶实现
   的负对数似然高 41.77（7502.751306 对 7544.520922）。
4. 相干矩阵的非对角元用「模 `ρ ∈ [0, 0.99]`、相位 `θ ∈ (−π, π]`」参数化，Hermitian
   性由构造保证（对角元恒为 1）；模态形状在各阶单位球的切空间内参数化。
5. 谱密度的优化边界按数据量纲取（`d_scale = mean|F_k|²`，上下界 `d_scale·1e±8`）。
6. 输出前按频率升序重排各阶，`S` 的行列、`V_ij` 与 `phi` 的列同步重排，并统一
   各阶模态形状的符号：第 i 阶整体反号时 `U_i → −U_i`，把 `S` 的第 i 行与第 i 列
   反号即可恢复 `E_k`，不能改为反号 `V_ij`（其对角元被约束为 1）。
